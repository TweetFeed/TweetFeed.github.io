About #PHP2Shell

  • CVEs: CVE-2026-109618 (OOM corruption), CVE-2026-109619 (stale global state).
  • Severity: CVSS 4.0: 9.2 (PHP). NVD CVSS 3.1: 9.8 and 8.1.
  • Impact: Unauthenticated RCE.
  • Third CVE: CVE-2026-115560: rare session setup. Fix in the next release.
  • At risk: PHP-FPM, mod_php (highest risk), php-cgi, FrankenPHP, LiteSpeed.
  • Fixed in: 8.5.12, 8.4.27, 8.3.36, 8.2.35, or a distro backport.
  • Name: Researcher name. PHP does not use it.
  • Tracked: #PHP2Shell posts on X, every 15 min.
  • Sources: php.net · GHSA 109618 · GHSA 109619 · NVD 109618 · NVD 109619

Recommendations

  1. Patch now: Every runtime: FPM, mod_php, CLI, containers. No full mitigation exists.
  2. Packages: Fixed: Debian 12/13, Ubuntu, RHEL 8/9/10, Remi, Docker. Not yet: RHEL 9 php:8.4.
  3. Restart: PHP-FPM and Apache. Rebuild images with docker build --pull.
  4. PHP 8.1 and older: Vendor backport, or source branches 7.4, 8.0, 8.1.
  5. Interim, 109619 + 115560: session.upload_progress.enabled=0; on 8.5 also fatal_error_backtraces=0. In php.ini or the FPM pool, not .user.ini. Restart workers.
  6. Interim, 109618: memory_limit=-1 via php_admin_value, plus a cgroup memory limit per worker. No RLIMIT_AS or RLIMIT_DATA.
  7. Edge: Low post_max_size. Cap request size, multipart parts and headers. Block multipart if unused.
  8. Hunt: PHP workers that start shells or downloaders. Fatal errors in PHP logs (GHSA). A clean log is not proof.
  9. Detect: ET Open php2shell rules, GreyNoise tags. The Nuclei check is intrusive.
  10. PoCs: Hundreds public, very few work (VulnCheck). Can be malware. Lab only.
  11. Share IOCs: Post on X with #PHP2Shell. In the feed within 15 min.

Advice changes as vendors publish. Check the linked sources before you act.

Frequently asked questions

What is PHP2Shell?

The researcher name for CVE-2026-109618 and CVE-2026-109619: two critical PHP flaws that allow unauthenticated RCE. PHP fixed them on 21 October 2026 in 8.5.12, 8.4.27, 8.3.36 and 8.2.35.

How do I protect my PHP servers from PHP2Shell?

Update PHP, restart every worker and rebuild container images. No full mitigation exists. Interim settings only reduce exposure.

How is this list updated?
